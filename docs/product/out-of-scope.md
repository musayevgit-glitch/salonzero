# Out of Scope (MVP)

Explicitly excluded per playbook Phase 0 instruction — revisit only via a written product decision:

- Payments and payment processing.
- Payroll.
- Marketplace commissions.
- Loyalty / rewards programs.
- In-app chat / messaging.
- Native mobile applications.
- AI-powered features (recommendations, auto-scheduling assistants, etc.).

These may be considered post-MVP once core reservation, tenant-isolation, and security requirements are
stable in production.
